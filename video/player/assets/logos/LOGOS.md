# Third-party logos

Used only in the getting-started tour: the wall of sources the import reads (`scenes/sources/wall.js`,
both cuts; the logical cut's without dbt), the export scene's Snowflake query card
(`scenes/rec/window.js`, `props.query`) and the Confluence scene (`scenes/tour/confluence.js`). Copied unchanged from `social-video/player/assets/logos/`
(video/ never loads anything from social-video/ at run time); the sources, terms and how each file
was vetted are in `social-video/player/assets/logos/LOGOS.md`, and are repeated here.

Each mark names the product it stands for, beside that product's name (nominative use); none
suggests endorsement. The marks remain their owners' trademarks. Colours are each brand's own,
unchanged. **Re-check the Microsoft and Atlassian terms (and each other owner's) before using any of
these marks in an ad or any other promotional use.**

Two names have no logo on purpose: **SQL** is a language, not a product (its chip is a plain
database glyph and the word), and **DBML** has no mark of its own. Fabric is named beside the Power
BI icon (Microsoft's Fabric icon set), not with a mark of its own.

**Compatibility wall (2026-11-10).** On Liam's decision, every source the import reads is shown with
its mark, in one same-size grid, so people recognise what they already use: each mark unaltered, in
its owner's colours, beside its name, and none presented as an endorsement. This supersedes the
earlier "MySQL has no logo" rule. The marks remain their owners' trademarks.
