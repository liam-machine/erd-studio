Auto

Models Tagged by Domain for Orchestration

Domain Tags

When models are added to a semantic domain, they're automatically tagged in their schema.yml. This enables domain-based dbt orchestration with varying refresh cadences—customer data hourly, finance daily, inventory weekly—based on actual reporting needs.

Domain-Based Refresh Orchestration
domain:customer-360 Hourly
dim_customer fct_orders dim_region
dbt build --select tag:domain:customer-360
domain:finance Daily
fct_gl_entries dim_cost_center fct_budget
dbt build --select tag:domain:finance
domain:inventory Weekly
dim_warehouse fct_stock_levels dim_product
dbt build --select tag:domain:inventory
domain:hr Monthly
dim_employee fct_timesheets dim_department
dbt build --select tag:domain:hr
